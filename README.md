# Salah Joja — Portfolio

Static portfolio site for [Salah Joja](https://github.com/salahjoja).

Live at **https://salahjoja.github.io**

## Contents

- `index.html` — portfolio homepage
- `styles.css` / `script.js` — site assets
- `assets/icons/` — technology icons
- `cv/` — printable CV pages (NestJS and Laravel tracks)

## Local preview

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploy

This repo is configured for GitHub Pages from the `main` branch root. Push to `main` to publish.
