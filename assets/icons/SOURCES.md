# Technology icon sources

The SVG technology marks in this directory are from
[Devicon](https://devicon.dev/), an open-source icon set distributed under the
MIT license. They were downloaded from the official Devicon GitHub repository
through jsDelivr.

The icons are decorative in the portfolio markup; the adjacent visible text is
the accessible technology label.

Included icons: NestJS, Node.js, TypeScript, Laravel, PostgreSQL, MySQL, Redis,
Sequelize, Prisma, Jest, OpenAPI (Swagger), Docker, GitHub Actions, Git.
Eloquent ORM uses a text badge (no Devicon mark).
