Decisions I'd defend

One deployable, not services
Cross-module transactions mattered more than service boundaries at this team size. The module split is real; I'd extract later, not now.
An aggregated endpoint instead of GraphQL
GraphQL is prettier on paper. Two clients, one engineer on the API, and a mobile shape I already knew — so I shipped /users/me/learn and cached it.
Cache invalidation beside the write
I write invalidation next to the write path on purpose. Hidden framework caching is how you get a stale learn tab and no idea why.
